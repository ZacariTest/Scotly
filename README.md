Scotly

Scotly es una plataforma de fantasía cultural inspirada en la mitología y la estética de Gran bretaña.

El proyecto combina:
- Elementos visuales
- Personajes coleccionables
- Gamificación ligera
- Sistemas de progresión inspirados en la fantasía

Actualmente en fase de prototipo inicial.
